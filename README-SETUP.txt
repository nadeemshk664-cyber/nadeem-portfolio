HOW TO PUBLISH ON GITHUB PAGES
1. Extract this ZIP file on your laptop.
2. Open your GitHub repository: nadeem-portfolio.
3. Upload index.html and the assets folder (keep the folder structure unchanged).
4. Commit the uploaded files to the main branch.
5. Open your GitHub Pages website and refresh after deployment.

HOW TO ADD YOUR RESUME LATER
1. Copy your updated resume PDF into this same folder (next to index.html).
2. Rename the PDF exactly: resume.pdf
3. Upload resume.pdf to the root of your GitHub repository, beside index.html.
4. Commit the change. The Resume button is already linked to resume.pdf.
